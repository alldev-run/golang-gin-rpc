# Security policy

## Supported versions

Security fixes are maintained for the latest `develop` and `main` branches.
Older revisions may not receive security updates. Releases are maintained on
`release-N.M` branches; fixes ship as patch tags on those branches (see the
[release policy](docs/operations/release-policy.md)).

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/alldev-run/golang-gin-rpc/security/advisories/new).
Do not open a public issue or pull request containing an unpatched vulnerability.

Include the affected version or commit, impact, reproduction details, and any
suggested mitigation. Avoid sending real credentials, personal data, or
production secrets. The maintainers will coordinate validation, remediation,
and disclosure with the reporter.
